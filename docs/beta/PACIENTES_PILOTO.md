# Pacientes Piloto

## Requisitos De Prueba

- Crear cuenta.
- Buscar especialidad o síntoma.
- Revisar perfil médico.
- Elegir horario.
- Crear ticket.
- Probar efectivo pendiente o Stripe test.
- Ver cita en panel.
- Recibir correo si SMTP está configurado.
- Solicitar cancelación/reagendamiento cuando aplique.
- Dejar opinión después de cita completada.

## Mensajes Importantes

- VITAEON no sustituye atención médica de urgencias reales.
- Los horarios dependen de disponibilidad publicada por médicos.
- Los reembolsos reales requieren revisión administrativa.
