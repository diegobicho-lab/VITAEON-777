# Launch Blockers

## Antes De Beta Privada

- PostgreSQL real configurado.
- SMTP real configurado.
- Stripe test configurado.
- Webhook Stripe test activo.
- QA paciente/médico/admin terminado.
- Deployment HTTPS estable.
- Variables de entorno completas.
- Admin inicial creado y contraseña cambiada.
- Seed limpio ejecutado.
- No hay perfiles demo visibles.

## Antes De Lanzamiento Público

- MFA admin.
- Redis o gateway para rate limiting multi-instancia.
- Stripe live.
- Backups automáticos y restauración probada.
- Monitoreo y alertas.
- Pruebas de penetración.
- Revisión legal completa.
- Storage privado con URLs firmadas.
- Políticas finales de privacidad, cancelación, reembolso y consentimiento.
- Procedimientos operativos para soporte, quejas y datos médicos.
