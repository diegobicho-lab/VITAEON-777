# Beta Ready Checklist

## Técnica

- `npm run typecheck` correcto.
- `npm run lint` correcto.
- `npm run test:unit` correcto.
- `npm run build` correcto.
- Migraciones aplicadas.
- Seed limpio ejecutado.
- No hay secretos hardcodeados.
- Robots bloquea indexación salvo `BETA_ALLOW_INDEXING=true`.

## Producto

- Home premium intacta.
- Flujo de cita probado.
- Ticket visible.
- Panel paciente probado.
- Panel médico probado.
- Panel admin probado.
- Modo Beta Privada visible solo en admin.
- Estados vacíos humanos.

## Operación

- Médicos piloto identificados.
- Pacientes piloto identificados.
- Soporte definido.
- Revisión legal pendiente marcada.
- Stripe test y SMTP validados.
